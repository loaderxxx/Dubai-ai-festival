# Публичная база плана и метод первоначального исследования

[English](../en/public-baseline.md)

## Что именно посчитано

Публичный источник события: [план Dubai AI Festival](https://dubaiaifestival.com/floorplan/) со [встроенным live-планом](https://floorplan.live/interactive/shows/4608/views/2/plan). Видимая таблица публичного плана зафиксирована **26 октября 2026 года в 03:30:39 UTC**. Сайты компаний проверены **26 октября 2026 года**.

| Показатель | Количество |
|---|---:|
| Заполненные строки таблицы плана | 264 |
| Различные нормализованные названия | 262 |
| Названия кандидатов-организаций | 248 |
| Объекты инфраструктуры и сервисы события | 12 |
| Коллективный павильон | 1 |
| Неизвестное название / возможный заполнитель | 1 |
| Первичные профили по официальным сайтам | 12 |
| Кандидаты без профиля на момент первоначального среза | 236 |
| Независимо подтверждённые уникальные юридические компании | **Не установлено** |

Документ сохраняет **первоначальный срез из 12 профилей**. Текущее объединённое покрытие начального и расширенного исследований находится в [полном реестре](../../research/ru/roster.md) и [данных покрытия](../../data/research-coverage.json). Выборки пересекаются; их нельзя складывать.

**Нельзя называть 264, 262 или 248 подтверждённым количеством компаний.** Название может обозначать бренд, продукт, учреждение, коллектив или совместную экспозицию. Наличие на публичном плане не устанавливает юридическое лицо, фактическое присутствие, работающий стенд, намерение купить или интерес к партнёрству. Организатор может изменять live-план.

Страница-обёртка перепроверена: она содержит iframe live-плана; часть навигации всё ещё относится к 2025 году. На самом зафиксированном плане обозначено событие 2026 года. Исходная публичная таблица сохранена с происхождением данных; закрытое приложение участников, доступный после входа каталог и персональные данные участников не использовались.

## Нормализация и классификация

- Unicode нормализуется по NFKC, повторные пробелы сводятся к одному, регистр не учитывается только при точной группировке названий. Исходные имена сохраняются.
- **Aecendir** указан на **G103 и S174**, **Grid Studio** — на **G105 и G104**. Каждое название объединено в одну запись с обоими стендами. Это устранение дублей названий, не слияние юридических лиц.
- Номер стенда никогда не является ID компании. **G103** указан для Aecendir, Handover AI, RSVD и TOTL Resource International LLC (TRI). На **G104** указаны Grid Studio и Jalubro; на **G105** — ATELIC AI и Grid Studio.
- Совместные названия, например **Habytat / Realm9** и **Exordium – BugLoud**, сохраняются до выяснения состава по источникам. Нельзя без доказательств разделять их на компании.
- **India Pavilion** — коллективная экспозиция, не отдельная компания. Состав не установлен.
- **RSVD** сохранён как неизвестное название, возможно обозначающее зарезервированное место; нужно подтверждение организатора.
- К инфраструктуре и сервисам отнесены 12 названий: Activation Zone; Cafe. Food Trucks; Dubai AI Festival 2027 Sales Stand; Helpdesk; INNOVATION STAGE; Investors Lounge; MOU Signing Stage; Photo Op; PLENARY; PREMIUM LOUNGE; Press & Media Zone; START-UP STAGE.
- У **Press & Media Zone нет номера стенда** в источнике; сохраняется null, местоположение не выдумывается.
- Учебные учреждения и медиабренды остаются кандидатами-организациями. Имя файла `companies` — удобное обозначение исследовательского реестра, а не утверждение, что каждая запись является коммерческим юридическим лицом.

## Стандарт доказательств

1. **Участие в событии:** название на публичном плане и номер стенда с исходными номерами строк и временем наблюдения.
2. **Идентичность:** отдельно установить официальный сайт бренда. Сохранять неоднозначность; не угадывать домен по распространённому имени. Совпадение бренда не подтверждает юридическое лицо экспонента.
3. **Предложение:** краткий пересказ официальных страниц продукта и документации с ID источника, URL, датой проверки и указанием раздела. Заявления поставщика не являются независимой проверкой эффективности.
4. **Пользователи и покупатели:** явно названные пользователи могут быть фактами; предполагаемые роли покупателей остаются гипотезами аналитика до подтверждения.
5. **Интерфейс интеграции и интерес:** API, SDK, коннекторы и публичные списки экосистем могут быть фактами. Готовность интегрироваться, покупать, сотрудничать или совместно продавать **неизвестна**, пока не получены отдельные доказательства.
6. **Кросс-ресёрч:** документированные связи поставщиков, предлагаемое взаимодополнение и конкурентное пересечение разделены. Для каждого ребра указаны ID фактов, вопрос для проверки и границы внедрения. Ребро не означает партнёрство.
7. **Без выдуманной приоритизации:** первая выборка отражает релевантность теме, но не рейтинг квалифицированных лидов. Бюджеты, лица принятия решений, ROI, сроки покупки и баллы готовности не выводятся.

Первая выборка из 12 профилей: AWS, Alibaba Cloud, Atlan, ClickUp, Elastic, ElevenLabs, Snowflake, Haptik, ONLYOFFICE, Applause, PlaceOS и XenonStack. Английская и русская версии содержат эквивалентные факты, гипотезы и источники.

## Что осталось

На момент первоначального среза **236 названий кандидатов** не имели профиля. [Текущий реестр](../../research/ru/roster.md) учитывает последующее исследование. Для кандидатов, пока не имеющих профиля, сначала нужно установить публичную идентичность, затем применить ту же структуру фактов и гипотез. Общие стенды, распространённые имена и совместные названия следует разрешить до изменения числа сущностей. Полное исследование всех кандидатов **не завершено**.

Следующий этап доказательств для каждого кандидата: официальный сайт → предложение и клиентский сценарий → интерфейсы интеграции → публичное подтверждение → пересечение/взаимодополнение → вопросы проверки. Документ описывает первоначальную базу с приоритетом доказательств. [Текущие правила источников](source-policy.md) определяют повторно используемые принципы для последующего исследования.

## Данные и воспроизводимость

- `data/floorplan-source-2026-10-26.json`: исходная публичная фиксация с происхождением.
- `data/floorplan-rows.{json,csv}`: все 264 строки со ссылками на сущности.
- `data/entities.{json,csv}`: все 262 названия с типами.
- `data/companies.{json,csv}`: 248 кандидатов-организаций, статусы исследования/идентичности и ссылки на проверенные сайты брендов у исследованных записей.
- `data/company-profiles.json`, `data/sources.json`: первичные двуязычные доказательства и реестр источников.
- `data/crossresearch.{json,csv}`: типизированные связи между компаниями.
- `research/en/roster.md`, `research/ru/roster.md`: полный реестр кандидатов с текущим объединённым покрытием.
- `data/research-coverage.json`: производное текущее покрытие с отдельным сохранением чисел первоначальной выборки.

Из корня пакета:

```sh
python scripts/normalize_floorplan.py
python scripts/build_initial_profiles.py
python scripts/normalize_floorplan.py
python scripts/build_crossresearch.py
python scripts/build_rosters.py
python scripts/validate_public_research.py
```

Скрипты пересоздают только локальные файлы; они не собирают данные из закрытых систем, не связываются с компаниями и не выполняют авторизованные запросы. Веб-источники проверены вручную; пересоздание файлов не перепроверяет актуальный интернет.
