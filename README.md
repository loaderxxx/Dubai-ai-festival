# Dubai AI Festival — public research

English is the primary language. [Русская версия](README.ru.md).

Public-source company research for Dubai AI Festival 2026. This repository contains no authenticated attendee directory, private biographies, contact details or account screenshots.

## Current coverage

- 264 public floorplan rows / 262 distinct display labels.
- 248 candidate organization labels, not a verified legal-company count.
- 12 initial bilingual company profiles; **236 candidates not yet researched**.
- 23 official web sources, 37 source-linked facts.
- 14 typed cross-research edges: documented links, complementarity hypotheses and competitive-overlap inferences remain distinct.
