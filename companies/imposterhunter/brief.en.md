Checked **26 October 2026, Asia/Dubai**. Independent public research; functionality untested.

**What it sells — VENDOR CLAIM:** LLM Shield is an input-classification API for prompt injection, jailbreak and conversation-level deception. Six advertised live surfaces share one engine: chat, voice transcripts, agents, MCP responses, RAG and memory. It returns scores, quoted evidence and recommended actions; the customer application enforces policy. Hosted, VPC, on-premises and air-gapped deployments are advertised. [IH03](https://imposterhunter.com/llm-shield)

**Hard boundaries:** voice screening operates on transcripts, not audio. MCP screening does not establish complete protocol authorization. Memory recall is screened; writes can be routed through the API, but it does not clean an existing memory store. These distinctions matter when scoping a pilot.
