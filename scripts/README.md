# Rebuild and validate / Пересборка и проверка

[Home](../README.md) · [Главная](../README.ru.md) · [Data guide](../data/README.md)

Run these commands from the repository root with Python 3. The scripts operate on local public files. They do not contact exhibitors or access private systems.

Запускайте команды из корня репозитория с Python 3. Скрипты работают с локальными публичными файлами, не связываются с экспонентами и не обращаются к приватным системам.

## Check the bundle / Проверить набор

```sh
python scripts/validate_atlas_expansion.py
python scripts/validate_public_research.py
python scripts/validate_navigation.py
python scripts/validate_value_chain.py
python scripts/audit_public_tree.py
python scripts/test_research_coverage.py
```

| Check | What it establishes | What it does not establish |
|---|---|---|
| `validate_public_research.py` | Original row conservation, entity classification, original profile/edge references, bilingual fields, CSV parity and existing relative-file targets | Fresh external-source review, legal identity, physical attendance, vendor performance or commercial intent |
| `validate_navigation.py` | Relative Markdown targets and heading anchors, accessible image labels, safe self-contained SVG structure, and no raw-HTML dependency in navigation pages | GitHub rendering in every client, live external-link health or source accuracy |
| `validate_value_chain.py` | Expanded company/source/claim/relationship references and coverage consistency | Tested product compatibility, benchmarked outcomes or confirmed commercial intent |
| `audit_public_tree.py` | Public-tree boundary checks, passive SVGs and local path / anchor integrity | Proof that every possible sensitive datum has been detected |
| `test_research_coverage.py` | Regression tests for joined coverage, report anchors, invalid / duplicate IDs and baseline-only fallback | Completeness or factual quality of the external research |

Проверки подтверждают локальную целостность, ссылки и структуру, **не** текущую достоверность внешних источников, посещение мероприятия или намерения компаний.

## Rebuild the original baseline / Пересобрать исходную базу

```sh
python scripts/normalize_floorplan.py
python scripts/build_initial_profiles.py
python scripts/normalize_floorplan.py
python scripts/build_crossresearch.py
python scripts/build_rosters.py
python scripts/validate_public_research.py
python scripts/validate_navigation.py
python scripts/validate_value_chain.py
python scripts/audit_public_tree.py
python scripts/test_research_coverage.py
```

The repeated normalization step joins the original profiles back to the candidate records. The roster builder also incorporates the expanded study when its public company register is present. **Do not mistake a regenerated timestamp or a passing test for a fresh web review.**

Повторная нормализация связывает исходные профили с записями кандидатов. Построитель списка также учитывает расширенное исследование, если его публичный реестр присутствует. **Пересборка или успешный тест не означают новой проверки сайтов.**

## Generated versus editorial / Генерация и редактура

- **Original data, profiles and edges:** generated by the existing baseline scripts from the public snapshot and manually reviewed evidence. / **Исходные данные, профили и связи:** строятся из публичного снимка и вручную изученных источников.
- **Current roster and coverage:** derived from the original and expanded study. / **Текущий список и покрытие:** объединяют исходное и расширенное исследование.
- **Expanded reports and registers:** research artifacts, not recreated by the original baseline builders. / **Расширенные отчёты и реестры:** исследовательские материалы, не генерируются исходными скриптами.
- **Landing pages, guides and SVGs:** editorial navigation; updating evidence may require updating these summaries. / **Главные страницы, путеводители и SVG:** редакторская навигация; при изменении доказательств резюме тоже нужно обновить.

Keep the baseline and expanded schemas distinct unless a deliberate migration updates every consumer and validator. Never make a historical count look current by changing a number without changing the underlying records.

Не смешивайте структуры исходного и расширенного исследования без явной миграции всех потребителей и проверок. Нельзя делать историческое число «текущим», меняя только число без записей.

## Atlas expansion checks / Проверки расширения

`validate_atlas_expansion.py` verifies company/profile/source coverage and speaker/session/topic references in the newer public directories. It does not re-fetch websites or establish legal identity, attendance, delivered talks, tested integrations or commercial intent. Проверяет структуру и ссылки новых публичных разделов, но не достоверность сайтов, юридическую идентичность, посещение, содержание выступлений или коммерческие намерения.
