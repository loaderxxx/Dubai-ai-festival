## Покрытие

- 264 строки публичного плана / 262 отображаемых названия.
- 248 названий кандидатов-организаций, не проверенное число юридических компаний.
- 12 начальных двуязычных профилей; **236 кандидатов ещё не исследованы**.
- 23 официальных веб-источника, 37 подтверждаемых источниками фактов.
- 14 связей кросс-исследования: подтверждённые связи, гипотезы взаимодополнения и выводы о конкурентном пересечении разделены.
