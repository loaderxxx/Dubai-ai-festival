# Visual assets / Иллюстрации

[Home](../README.md) · [Главная](../README.ru.md)

Original, dependency-free SVG illustrations created for this research repository. They contain no company logos, tracking pixels, scripts, external fonts or embedded remote images. Generic pictograms communicate research roles, not endorsements.

Оригинальные SVG для этого репозитория без внешних зависимостей. В них нет логотипов компаний, трекинга, скриптов, внешних шрифтов или удалённых изображений. Условные пиктограммы обозначают роли, а не рекомендации компаний.

Each SVG includes an accessible title and description; Markdown embeds include descriptive alternative text. The role map is also available as a searchable [English table](../research/en/README.md#browse-by-role) / [таблица на русском](../research/ru/README.md#навигация-по-ролям). Labels, not color alone, convey meaning.

Каждый SVG содержит доступные заголовок и описание, а в Markdown — альтернативный текст. Роли также доступны в текстовых таблицах. Значение передаётся подписями, а не только цветом.
