## Reading the layer matrix

Nine columns describe **scope in the linked profiles**, not objective company-wide capability scores: models, infrastructure, data, governance, agents, vertical apps, delivery, distribution and ecosystem. `1` means a sourced offering/role is represented; `0` means it is not established in this scope, not proof of absence. Supplier-claimed features remain supplier claims. ImposterHunter's proprietary classifier maps to models; input screening to data/governance. Its agent protection is **not** evidence that it builds general-purpose agents. Kira/KB/Integra/Campus/Terrapinn rows retain the earlier scoped classification; AWS is limited to hosting and guardrail controls relevant here.

**Selection rule — INFERENCE:** choose a real workflow and accountable owner before a vendor pairing. Establish the API and data terms, measure the existing baseline, then evaluate a reversible boundary. No outreach, operational API call, benchmark or deployment was performed.
